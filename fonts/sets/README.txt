Devanagari subsets of SIL Open Font License fonts, made for the font style explorer and the ligature chart.
Google Fonts serves these families without their optional stylistic sets (ss01 …, salt), so these copies keep
all OpenType layout features. Changes: variable fonts instanced at Regular (wght 400, wdth 100), glyphs subset to
Devanagari, Vedic extensions, basic Latin and punctuation, converted to WOFF2 with fontTools.
Each family's licence is in the matching *-OFL.txt file; none of these families declares a Reserved Font Name.
